# Referências e fundamento das recomendações

> Conferência editorial: 29/10/2026. Atualize versão e status das fontes ao revisar o processo. O uso de uma referência não significa certificação de conformidade.

| Fonte oficial | Utilização |
| --- | --- |
| [Manifesto Ágil e princípios](https://agilemanifesto.org/iso/ptbr/principles.html) | Feedback, software funcional e adaptação |
| [Scrum Guide 2020](https://scrumguides.org/scrum-guide.html) | Scrum e Definition of Done; não impõe Sprint 0 |
| [GitHub Best Practices](https://docs.github.com/en/repositories/creating-and-managing-repositories/best-practices-for-repositories) | README, segurança, contribuição |
| [GitHub Pull Request Standardization](https://docs.github.com/en/pull-requests/reference/managing-and-standardizing-pull-requests) | PR template, CODEOWNERS e proteção |
| [NIST SSDF SP 800-218 v1.1 final](https://csrc.nist.gov/pubs/sp/800/218/final) | Desenvolvimento seguro e gestão de vulnerabilidades |
| [OWASP ASVS 5.0.0](https://asvs.owasp.org/) | Verificação de segurança de aplicação web |
| [WCAG 2.2 — W3C](https://www.w3.org/TR/WCAG22/) | Requisitos verificáveis de acessibilidade |
| [OpenAPI Specification](https://spec.openapis.org/oas/latest.html) | Contratos de API quando aplicável |
| [C4 model](https://c4model.com/) | Diagramas de arquitetura opcionais |
| [Diátaxis](https://diataxis.fr/) | Organização de guias e referências documentais |
| [LGPD — Lei 13.709/2018](https://www.planalto.gov.br/ccivil_03/_ato2015-2018/2018/lei/l13709.htm) | Avaliar proteção de dados no Brasil |
| [ANPD](https://www.gov.br/anpd/pt-br) | Orientações sobre dados pessoais |

O NIST SSDF 1.2 foi publicado como **rascunho** em dezembro de 2025; esta proposta adota v1.1 final. Técnicas como número de entrevistas, pirâmide de testes, TDD, Docker e sprints com duração fixa são práticas contextuais, não normas universais.
